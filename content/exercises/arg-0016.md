Corvane is about to release a new version of its delivery-tracking app. The company's release rule is
that, in its standard tests on every phone the app supports, the map screen must finish updating within
half a second of a driver's new location arriving. The screen is built from forty separate components,
among them the map itself, the driver's marker and the estimated arrival time. In the standard tests,
testers ran each component on its own on every supported phone, and every component finished updating in
under half a second each time. The release manager concludes that the new version's map screen meets the
half-second rule.
