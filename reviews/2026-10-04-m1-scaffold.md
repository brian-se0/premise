You are the same senior software architect who reviewed the Premise specs in three rounds (v0.1 to v0.3, then v0.4/v0.5 were accepted). This is the first **code** review: milestone M1, the site scaffold and the content build. Review the diff below for:

1. Correctness against `EXERCISE_FORMAT.md` §4 (the 14 validation rules) and §3 (schema 3). Does each rule do what the spec says, and does each failing-fixture test actually prove its rule?
2. 5. Over-engineering: flag anything heavier than a one-owner study app needs.

## 2. Context

Premise is a free, open-source static web app (no server, no network at runtime) that trains reasoning skills for law-school admission exams without using any official content or branding. Students write answers to short original arguments; any chatbot grades them from a copy-pasted prompt that ends in a fixed score block the student pastes back; the app schedules redos with FSRS. Code AGPL-3.0-only; content CC BY-NC-SA 4.0. The owner has decided to build the app end to end before finishing the M0 grading pilot (decision entry in the diff). M1 acceptance: `npm run check` passes in CI; the deployed site loads a deep link and shows About; each §4 rule has a failing-fixture test.

Already existing before M1 (unchanged except formatting): `src/domain/prompt.ts` (prompt builder v2), `src/domain/snapshot.ts` (snapshot payload and SHA-256 hash, sorted-key JSON), `src/domain/credit.ts`. The diff includes `docs/EXERCISE_FORMAT.md` and `docs/DECISIONS.md` changes. The 8 exercises in `content/exercises/` are drafts.

## 3. Response format

Numbered findings (M1-1, M1-2, ...), each with severity (blocker, major, minor, nit), file and line or section, the problem, and a proposed fix. Then a one-line verdict: merge as is, merge after fixes, or not ready.

+function inline(text: string): ReactNode[] {
+  return text.split(EMPHASIS).map((part, i) => {
+    if (part.startsWith('**') && part.endsWith('**') && part.length > 4)

+      if (part.length > 2) return <em key={i}>{part.slice(1, -1)}</em>;
+    }
+    return part;
+  });
